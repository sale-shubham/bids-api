# Admin (SUPER_ADMIN only)

All routes are under `/admin` and require `authenticate` + `requireRole('SUPER_ADMIN')`. Code: `src/modules/admin/{dashboard,members,auctions,commissions,payments,sales,reviews,reports,settings,retention,strikes,risk}`. With `REQUIRE_ADMIN_2FA=true` every route here answers 403 `TWO_FACTOR_SETUP_REQUIRED` for a Super Admin who has not enabled 2FA (`auth.md`). Lists use `paginated()` (`meta: { total, page, pageSize, totalPages }`, `page` / `pageSize` max 100).

| Method | Path | Notes |
|---|---|---|
| GET | `/admin/dashboard` | `{ salesByStatus: { <SaleStatus>: { count, amountPaise } } (every status, zero-filled), totals: { members, bidders, auctioneers, liveAuctions, upcomingAuctions, endedAuctions, bidsToday, commissionPaidPaise, commissionDuePaise }, revenueByMonth: [{ month 'YYYY-MM', paidPaise }], signupsByMonth: [{ month, bidders, auctioneers }], recentAuctions: AuctionCard[5] }`. Both series cover the last 12 calendar months (IST), oldest first, zero-filled. Revenue = PAID commissions by `paidAt`. `bidsToday` counts from IST midnight. |
| GET | `/admin/members` | `q` (name/email/phone), `role`, `status=active\|inactive`, `sortBy`, `sortOrder`, paging -> `{ id, name, email, phone, role, isActive, emailVerifiedAt, phoneVerifiedAt, verified: boolean, twoFactorEnabled: boolean, payoutStatus: PayoutStatus\|null, activeStrikes: number, createdAt, unpaidCommissionPaise, auctionsWon, moneySpentPaise }[]` + top-level `stats { total, active, inactive }` |
| PATCH | `/admin/members/:id` | `{ isActive?, role?, verified? }` (at least one) -> `{ member }` (same DTO as the list). `verified: false` revokes the seller badge (`verificationRevokedAt = now`, `verifiedAt` cleared; wins over the rule); `verified: true` clears the revoke and re-runs `refreshSellerVerification` (badge only returns if phone + ACTIVE payout account hold). A role change also re-evaluates it. 409 `CANNOT_MODIFY_SELF` if the target is the caller and the body changes role or sets `isActive: false`. Deactivation deletes the member's Sessions and force-disconnects their sockets. 404 for unknown id. |
| GET | `/admin/auctions` | `status=live\|upcoming\|ended\|cancelled` (omit = all), `q` (title, seller name/email) -> `AuctionCard & { sellerEmail, depositPaise: number|null }`, newest first. Cancel with `DELETE /auctions/:id` (admin may cancel auctions that have bids; no refund/notify, logged). |
| PATCH | `/admin/auctions/:id/deposit` | `{ depositPaise: integer >= 0 \| null }` (0 / null = no deposit) -> `{ auction: { id, depositPaise } }`; 409 `AUCTION_ENDED` once ended / cancelled. See `deposits.md` |
| GET | `/admin/members/:id/strikes` | `{ items: StrikeDTO[] }`. See `strikes.md` |
| POST | `/admin/strikes/:id/remove` | `{ note? <= 500 }` -> `{ strike }`; does not unsuspend (use `PATCH /admin/members/:id`); 404 `STRIKE_NOT_FOUND`, 409 `STRIKE_ALREADY_REMOVED` |
| GET | `/admin/risk` | `status=open\|reviewed` (default open), paging -> shill-bid signals, highest score first. See `risk.md` |
| PATCH | `/admin/risk/:id` | `{ outcome: DISMISSED\|ACTION_TAKEN, note? <= 500 }` -> `{ signal }`; 404 `RISK_SIGNAL_NOT_FOUND`, 409 `RISK_ALREADY_REVIEWED` |
| GET | `/admin/reports` | moderation queue, `status`, `targetType`, paging -> items with `target { label, url }`, `openCountForTarget`, `priority` (`HIGH` at >= 3 open on one target). See `reports.md` |
| PATCH | `/admin/reports/:id` | `{ status: ACTION_TAKEN\|DISMISSED, note?, applyToAllOpenForTarget? }` -> `{ report, resolvedCount }`; the action itself uses the existing cancel / suspend / hide endpoints |
| GET | `/admin/reviews` | `hidden=true\|false` (omit = all), `q` (comment, reviewer or seller name/email), `page`, `limit` (alias `pageSize`, max 100) -> `AdminReviewDTO[]` newest first: ReviewDTO + `hiddenAt`, `reviewer { id, name, email }`, `seller { id, name }` |
| PATCH | `/admin/reviews/:id` | `{ hidden: boolean }` -> `{ review }`. Hiding subtracts the rating from the seller's `ratingCount` / `ratingSum`, unhiding adds it back; repeating the same value changes nothing. 404 `REVIEW_NOT_FOUND`. See `reviews.md` |
| GET | `/admin/sales` | `status`, `q`, `page`, `limit` (alias `pageSize`) -> paginated `SaleDTO` (role ADMIN) with buyer / seller emails. See `checkout.md` |
| POST | `/admin/sales/:id/release` | DISPUTED\|DELIVERED -> RELEASED -> `{ sale }`; 409 `SALE_INVALID_STATE`, 502 `RELEASE_FAILED` |
| POST | `/admin/sales/:id/refund` | `{ note? <= 500 }` PAID\|SHIPPED\|DELIVERED\|DISPUTED -> REFUNDED (refund with `reverse_all`, PAID commission row WAIVED) -> `{ sale }`; 409 `SALE_INVALID_STATE` / `SALE_NO_PAYMENT` |
| GET | `/admin/commissions` | `status=due\|paid\|waived\|all` (default due) -> `CommissionDTO & { seller: { id, name, email } }` |
| POST | `/admin/commissions/:id/waive` | `waiveCommission` -> `{ commission }`; 404 `COMMISSION_NOT_FOUND`, 409 `COMMISSION_NOT_DUE`; reduces the seller `unpaidCommissionPaise` (never below 0) |
| GET | `/admin/payments` | `status=created\|paid\|failed` (omit = all) -> `{ id, member: { id, name, email }, amountPaise, status (CREATED\|PAID\|FAILED), gatewayOrderId, gatewayPaymentId, referenceType, referenceId, createdAt }[]` |
| GET / PUT | `/admin/settings` | `{ commissionRateBps 0-3000, minIncrementPaise >= 100, antiSnipingMinutes 0-30, maxPricePaise 100000..1000000000000 (default 10000000000), categories?: string[] (deprecated and ignored on PUT; GET returns the active root category names, sorted), checkoutMode 'off'\|'optional'\|'required' (default optional), depositThresholdPaise 0..1000000000000 (default 10000000 = Rs 1 lakh, 0 = deposits off), depositRateBps 100..5000 (default 1000) }` (`categories` on PUT: if sent it must still be 1-30 unique, 2-40 chars each, but it is ignored: manage categories at `/admin/categories`). `maxPricePaise`, `checkoutMode`, `depositThresholdPaise` and `depositRateBps` are optional on PUT: when absent the stored value is kept (`checkout.md`, `deposits.md`). PUT replaces the rest of the object in one transaction and returns the whole object. Takes effect for new closes / bids / listings. |
| GET | `/admin/categories` | flat category list incl. inactive with `auctionCount`; see `categories.md` |
| POST | `/admin/categories` | create (name, slug?, parentId?, sortOrder?, isActive?, description?, attributeSchema?) -> 201 `{ category }`; 409 `CATEGORY_SLUG_TAKEN` |
| PATCH | `/admin/categories/:id` | update; 400 `CATEGORY_CYCLE`, 409 `CATEGORY_SLUG_TAKEN`, 404 `CATEGORY_NOT_FOUND` |
| DELETE | `/admin/categories/:id` | 409 `CATEGORY_IN_USE` when it has auctions or children |
| GET / PUT | `/admin/settings/legal[/:slug]` | see `legal-pages.md` |
| GET / PUT | `/admin/settings/device-limit` | per-role device cap |
| POST | `/admin/retention/purge` | manual retention purge (also deletes `AuctionViewer` rows older than 30 days; the result has `auctionViewersDeleted`; `analytics.md`) |

Removed: `GET /admin/overview`, `POST /admin/members/:id/{activate,deactivate}`, `PATCH /admin/members/:id/role` (replaced by `/admin/dashboard` and `PATCH /admin/members/:id`).
